- **Agentic Wallet pending-status cadence enforcement, injected clock, runner-boundary deferral, M10.50:** start with `real-trading.md`, `roadmap.md`, `decisions.md`, and `current-state.md`; implementation is in `../src/modules/real-trading/infrastructure/agentic-wallet-market-swap-status-reconciliation-attempt.ts` and `../src/modules/real-trading/infrastructure/agentic-wallet-market-swap-status-lookup-cadence.ts`.
